# Development Roadmap

- **Phase 1: Foundation & Project Scaffolding (Current)**
  - Milestone 1: Environment inspection, audit, legacy preservation, Android Gradle scaffold (AGP 9.2.1, API 36, Compose, Hilt), documentation, and baseline build verification.
- **Phase 2: Core Device Telemetry & Pairing**
  - Socket.io connection, initial state handshakes, device registration, and battery status reporting.
- **Phase 3: Battery-Optimized Location & Geofencing**
  - Fused location provider, adaptive ping throttling, geofence boundary alerts.
- **Phase 4: App Rules & Screen Time Management**
  - Usage stats API integration, app blocking, emergency phone lock.
- **Phase 5: Notification Mirroring**
  - NotificationListenerService integration and mirror payload relay.
- **Phase 6: Remote Inspection & Live Streams**
  - WebRTC signaling for camera, microphone, and screen mirror.
